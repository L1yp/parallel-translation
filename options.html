基础翻译

整页翻译的全局默认：目标语言、翻译服务、双语对照样式与动态内容支持。可被"站点规则"按域名覆盖。

悬停翻译

不开整页翻译时，按住修饰键 + 悬停段落即时翻译单段，零侵入。

划词翻译

选中文本后弹出气泡显示译文；命中单个词时显示词典释义（音标、词性、例句）。

输入框翻译

在 <textarea> / <input> / contenteditable 中连按多次空格触发翻译，按"源语言 → 目标语言"方向替换。中文输入法的空格选词不会被拦截。

翻译服务凭证

仅本扩展可见；同步到 chrome.storage.sync，与偏好分开存放。Google 免费接口无需凭证。

Microsoft Translator

使用 Azure 认知服务的 Translator 资源。需要在 Azure 门户 创建资源后获取 Key 与所在 Region。免费层 F0 每月 200 万字符。

有道智云翻译

使用网易有道智云平台的翻译 API。需要在 有道智云控制台 创建"文本翻译"应用后获取 App Key 与 App Secret。新用户赠送约 500 万字符的免费额度。

站点规则

为特定域名定制偏好（目标语言、翻译服务、悬停 / 划词 / 输入框翻译 等）。 命中时覆盖全局设置；多条规则匹配同一域名时，pattern 最长者优先。 支持 example.com（含子域）或 *.example.com（仅子域）。
