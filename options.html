基础翻译

整页翻译的目标语言、使用的翻译服务、双语对照样式与动态内容支持。

悬停翻译

不开整页翻译时，按住修饰键 + 悬停段落即时翻译单段。

划词翻译

选中文本后弹出气泡显示译文；命中单词时显示词典释义。

输入框翻译

在 <textarea> / <input> / contenteditable 中连按多次空格触发翻译，按"源语言 → 目标语言"方向替换。中文输入法的空格选词不会被拦截。

Microsoft Translator

使用 Azure 认知服务的 Translator 资源。需要在 Azure 门户 创建资源后获取 Key 与所在 Region。免费层 F0 每月 200 万字符。

有道智云翻译

使用网易有道智云平台的翻译 API。需要在 有道智云控制台 创建"文本翻译"应用后获取 App Key 与 App Secret。新用户赠送约 500 万字符的免费额度。

本地缓存

相同段落短期内重复翻译命中缓存，省流量、扛限流。TTL 7 天，容量上限 5000 条， 超出按时间淘汰最旧的。key 包含翻译服务、源/目标语言、词典模式，互不污染。
